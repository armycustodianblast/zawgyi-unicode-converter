## 💡 Understanding the Problem

Myanmar (Burmese) text exists in **two encoding systems** that are visually incompatible:

1. **Zawgyi** — A legacy non-standard encoding, widely used before 2019
2. **Unicode** — The official international standard, mandated by the Myanmar government since 2019

Text written in one system appears as **garbled boxes or misplaced characters** when viewed with the other. This tool bridges the gap — instantly converting between both standards with zero data loss.

### The Core Difference

| Aspect | Zawgyi | Unicode |
|--------|:------:|:-------:|
| 📅 Era | Pre-2010 | Modern |
| 🏛️ Status | Legacy, deprecated | Official standard |
| 🔤 Encoding | Custom mapping | UTF-8 compliant |
| 🌐 Internet | Old websites | Modern web |
| 📱 Mobile | Old phones | Android/iOS |
| 🖥️ OS Support | Manual fonts | Native |
| 📖 Reading | Widespread | Growing |
| 🔮 Future | Phasing out | Permanent |

## 🔄 How to Convert

### Method 1 — Copy & Paste

1. Copy Zawgyi text
2. Paste into input field
3. Click **Zawgyi → Unicode** or **Unicode → Zawgyi**
4. Result appears instantly

### Method 2 — File Upload

Drag `.txt`, `.docx`, `.pdf`, or `.html` file into the app.

### Method 3 — Batch Folder

**File → Batch Convert Folder** → select directory

### Method 4 — CLI

```bash
# Zawgyi to Unicode
zawgyi-unicode --from zawgyi --to unicode input.txt -o output.txt

# Unicode to Zawgyi
zawgyi-unicode --from unicode --to zawgyi input.txt -o output.txt

# Auto-detect
zawgyi-unicode --auto input.txt -o output.txt
```

### Method 5 — API

```bash
curl -X POST https://api.converter.example/convert \
  -H "Content-Type: application/json" \
  -d '{
    "text": "ေမ္းေအးေက်ာ္",
    "from": "zawgyi",
    "to": "unicode"
  }'
```

### Method 6 — Browser Extension

Install extension → right-click any text → **Convert to Unicode**
